#RaktaSewa
Blood Donation & Emergency Donor Finder System

📌 Project Overview
RaktaSewa is an Android-based mobile application developed as a TU BCA 6th Semester Major Project. The application aims to connect blood donors and seekers in a fast, reliable, and organized manner, especially during emergency situations. The system uses a smart matching mechanism to identify suitable donors based on blood group, location, and availability.

🎯 Objectives
To develop a mobile application for connecting blood donors and seekers.
To enable users to register and participate as donors or blood seekers.
To provide emergency and normal blood request features.
To reduce delays in finding suitable blood donors using intelligent matching.
To improve blood donation coordination through digital communication.

🛠️ Technologies Used
Programming Language: Java
Platform: Android
Backend & Database: Firebase (Authentication & Firestore/Realtime Database)
Development Environment: Android Studio
Model Used: Prototype Model

⚙️ Key Features
User registration and login
Donor registration and availability status update
Blood request creation (normal and emergency)
Smart donor matching based on blood group, location, and availability
Emergency priority notification system
Donor–seeker contact functionality
Simple and user-friendly interface

🧠 System Modules
User Authentication Module
Donor Management Module
Blood Request Management Module
Intelligent Matching Module
Emergency Notification Module

📊 Algorithms Used
Blood Group Matching Algorithm
Location-Based Donor Filtering Algorithm
Emergency Priority Matching Algorithm
